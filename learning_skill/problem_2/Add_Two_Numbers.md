# 2. Add Two Numbers
กำหนดให้คุณมีรายการเชื่อมโยง (linked list) ที่ไม่ว่างสองรายการ ซึ่งแทนจำนวนเต็มที่ไม่เป็นลบสองจำนวน โดยตัวเลขแต่ละหลักจะถูกจัดเก็บไว้ในโหนดตามลำดับย้อนกลับ (reverse order) และแต่ละโหนดจะเก็บตัวเลขเพียงหนึ่งหลักเท่านั้น จงหาผลรวมของจำนวนทั้งสองนี้ แล้วส่งคืนผลลัพธ์ในรูปแบบของรายการเชื่อมโยง คุณสามารถสมมติได้ว่าจำนวนทั้งสองไม่มีเลขศูนย์นำหน้า ยกเว้นกรณีที่เป็นตัวเลข 0 เพียงตัวเดียวเท่านั้น


Input: l1 = [2,4,3], l2 = [5,6,4]
Output: [7,0,8]
Explanation: 342 + 465 = 807.

Example 2:

Input: l1 = [0], l2 = [0]
Output: [0]

Example 3:

Input: l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
Output: [8,9,9,9,0,0,0,1]
