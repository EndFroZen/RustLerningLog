# การติดตั้ง RUST ครับ
- คิงเช็คก่อนว่า terminal หรือ คอมที่จะผึกมี RUST ก่ ```rustc --version``` ถ้ามีกะบ่อถ้าติดตั้ง
- ถ้ามีแต้ๆคิงลองใช้คำสั้งนี้ดูว่ามันจะทำงานก่อก่อนอื่นคิงต้องมันใจว่าอยู่ ``` /install_rust``` ถ้าอยู่แล้วลองรันอันนี้ดู ```cargo run``` ผลที่ได้เป็นแบบนี้ก็ถือว่าใช้งานได้
